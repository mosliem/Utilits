# Utilities Package 

  - Different UIKit Extensions.
      - UI Extensions that are used in most of the projects
      - Includes these types **[UIButton - UICollectionView - UIControlState - UIImage - UIImageView - UILabel - UINavigationBar - UIScrollView - UITableView - UITextField - UIView - UserDefaults]**
  
  
  - Generic Network Layer With Combine.
      -  Built with a Generic API Client that handles all request types ]
      -  Separated Layers [URL Builder - Request Builder - Network Manager - API Client].
      -  Build With Protocols.  
 
  
 - Localization Manager
      - Handles Setting Languages for the app even if the selected one is different from the system language.
      - Handles RTL and LTR in UIViews
